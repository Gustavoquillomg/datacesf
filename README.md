
# DataVotoCesf

Projeto escolar de pesquisa socioeconômica e de prioridades
da comunidade de Campo Largo/PR.

## Tecnologias

- HTML5
- CSS3
- JavaScript ES Modules
- Firebase Authentication
- Cloud Firestore
- Chart.js
- GitHub Pages

## Arquivos

- index.html: formulário público.
- admin.html: painel administrativo.
- style.css: estilos responsivos.
- firebase.js: configuração do Firebase.
- script.js: validação e gravação das respostas.
- admin.js: autenticação, métricas e gráficos.
- firestore.rules: regras de segurança do banco.

## Configuração

1. Crie um projeto no Firebase Console.
2. Registre um aplicativo Web.
3. Copie a configuração para firebase.js.
4. Crie o banco no Firestore Database.
5. Ative Email/Password no Authentication.
6. Crie a conta administrativa manualmente.
7. Copie o UID administrativo para firestore.rules.
8. Publique as regras no Firestore.
9. Teste o formulário em um servidor local.
10. Publique os arquivos no GitHub Pages.

## Publicação

No GitHub, abra Settings > Pages.
Escolha Deploy from a branch, a branch main e a pasta / (root).

## Privacidade

Não colete nomes, telefones, e-mails ou endereços completos.
Obtenha aprovação do professor para o questionário e o
tratamento dos dados. Divulgue apenas resultados consolidados.
